## Featured Projects

### Engineering Thesis - Action RPG Dungeon Crawler (Work in Progress)

My most advanced Unreal Engine project: a solo action RPG dungeon crawler that
connects a C++ inventory and equipment architecture with GAS-driven combat.
Weapons grant abilities and passive effects, armor modifies resistances,
enchantments affect damage and weapon trails, and loot chests generate
data-driven rewards.

The core player systems are functional. The first melee enemy and its State
Tree behavior are currently in development; ranged and magic enemies, a dragon
boss, bow combat, and magic staff abilities are planned.

**Highlights:** C++, Blueprints, GAS, Gameplay Tags, Fast Array replication,
UMG, Data Assets, custom damage execution, AI Perception, State Trees

[View the Engineering Thesis case study](EngineeringThesis/README.md)

---

### Inventory and Equipment System

A solo Blueprint project implementing a reusable inventory module with world
pickups, item stacking, drag and drop, equipment slots, containers, item use,
sorting, and SaveGame persistence. The system separates item data, storage, UI,
and world interaction.

**Highlights:** Blueprints, UMG, Actor Components, Blueprint Interfaces, Data
Tables, SaveGame

[View the Inventory System case study](InventorySystem/README.md)

---

### TheMorph

A gameplay prototype developed by a four-person team during a game jam. The
project centers on changing the player's physical form and using inventory items
to solve environmental puzzles.

**My contribution:** morph system, inventory, pressure plates, puzzle
interactions, and doors with item requirement validation

**Highlights:** Blueprints, Data Tables, collision queries, interaction systems,
team development

### Gameplay Ability System - Aura

A partially completed learning project based on Stephen Ulibarri's GAS course.
It introduced the core relationships between Gameplay Abilities, Gameplay

**Scope:** course implementation with minor modifications; included as a record

**Highlights:** C++, GAS, Gameplay Tags, Execution Calculations, Attribute
