## About Me

I am a Software Engineering student specializing in Unreal Engine gameplay
programming. Since 2021, I have been developing gameplay prototypes centered on
combat, AI, inventory, interaction systems, UI, and data-driven architecture.

I work with both C++ and Blueprints, choosing the tool that best fits the system.
My goal is to create gameplay code that is readable, modular, and easy to extend.
Professional experience in enterprise IT has also strengthened my approach to
problem analysis, debugging, documentation, and teamwork.

I am currently looking for a junior gameplay programming role where I can work
primarily with Unreal Engine.

## Featured Projects

### Inventory and Equipment System

A solo Blueprint project implementing a reusable inventory module with world
pickups, item stacking, drag and drop, equipment slots, containers, item use,
sorting, and SaveGame persistence. The system separates item data, storage, UI,
and world interaction.

**Highlights:** Blueprints, UMG, Actor Components, Blueprint Interfaces, Data
Tables, SaveGame

[View the Inventory System case study](InventorySystem/README.md)

---

### TheMorph

A gameplay prototype developed by a four-person team during a game jam. The
project centers on changing the player's physical form and using inventory items
to solve environmental puzzles.

**My contribution:** morph system, inventory, pressure plates, puzzle
interactions, and doors with item requirement validation

**Highlights:** Blueprints, Data Tables, collision queries, interaction systems,
team development

[View TheMorph project case study](TheMorph/README.md)

## Learning Projects

### Modular Combat System

A solo Blueprint learning project developed from a course-guided foundation. It
combines AI-controlled enemies, Behavior Trees, animation-driven hit timing,
damage and hit reactions, a boss encounter, and multiple weapon configurations.

**Scope:** gameplay implementation and system integration; visual and animation
assets are third-party

**Highlights:** Blueprints, Behavior Trees, Anim Montages, Anim Notifies,
gameplay AI

[View the Combat System case study](CombatSystem/README.md)

---

### Gameplay Ability System - Aura

A partially completed learning project based on Stephen Ulibarri's GAS course.
It introduced the core relationships between Gameplay Abilities, Gameplay
Effects, Attribute Sets, Gameplay Tags, custom calculations, replication
patterns, data-driven balancing, and UI.

**Scope:** course implementation with minor modifications; included as a record
of GAS learning rather than an independently designed project

**Highlights:** C++, GAS, Gameplay Tags, Execution Calculations, Attribute
replication, Data Assets, Curve Tables

[View the GAS learning case study](GameplayAbilitySystem/README.md)
